# LibraFlow — Community Library Management System

React web-based library management system for the Web Application Development assignment.

## Requirements implemented
- React Hooks (`useState`, `useEffect`)
- Component composition
- Controlled forms and validation
- React Router navigation
- Local Storage database
- Book add/update/delete
- Stock add/borrow transactions and history
- User login/add/update/delete
- Dashboard with low-stock highlighting
- Responsive UI

## Run
```bash
npm install
npm run dev
```
